# How it's made

I started by researching portfolios to get an idea of what features need to be included. I sketched a layout ideas for phones and computers. I think space is really beautiful and a symbol of the possibilities of the future. After choosing a few colors for the theme, I checked them for accessibility (accessibleweb.com). I also picked out a couple of fonts that I thought looked futuristic. Initially, I formatted the HTML using div containers, but I wanted a more strict struct. I switched to a grid template that helped contained the thumbnails for each project and keep them aligned on the page.
